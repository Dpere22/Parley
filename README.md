# Parley - A Modern Messaging Application

## Use Case
Parley is a web based real-time messaging application with a focus on a responsive UI and
real-time updates. Members join councils - group chats anyone may enter - and messages are
delivered live over a WebSocket rather than polled.

## Tech Stack
Parley utilizes fastapi for the backend and a modern react + reactrouter frontend to ensure
responsiveness. The frontend is written in TypeScript and styled with TailwindCSS.
